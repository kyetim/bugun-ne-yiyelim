## 📌 Proje Hakkında

"Bugün ne yiyelim?" sorusuna artık saatlerce düşünmek zorunda değilsin. Bu uygulama, rastgele yemek önerileri sunarak günlük yemek kararlarını kolaylaştırır. Sade tasarımı ve hızlı kullanımıyla tam bir günlük araç.

## ✨ Özellikler

- 🎲 Tek tıkla rastgele yemek önerisi
- 🍜 Çeşitli Türk ve dünya mutfağından yemekler
- 📱 Mobil uyumlu, responsive tasarım
- ⚡ Harici kütüphane gerektirmez — saf Vanilla JS

## 🛠️ Kullanılan Teknolojiler

| Teknoloji | Açıklama |
|-----------|----------|
| HTML5 | Sayfa yapısı ve semantik işaretleme |
| CSS3 | Stil ve responsive tasarım |
| Vanilla JavaScript | Uygulama mantığı ve DOM manipülasyonu |

## 🚀 Kurulum & Çalıştırma

Herhangi bir kurulum gerekmez. Projeyi klonla ve `index.html` dosyasını tarayıcında aç:

```bash
git clone https://github.com/kyetim/bugun-ne-yiyelim.git
cd bugun-ne-yiyelim
# index.html dosyasını tarayıcında aç
```

## 📁 Proje Yapısı

```
bugun-ne-yiyelim/
├── index.html    # Ana uygulama dosyası (HTML + CSS + JS)
└── README.md
```

## 🤝 Katkıda Bulunma

Pull request ve öneriler her zaman hoş karşılanır! Yeni yemek önerileri eklemek veya tasarımı geliştirmek istersen fork'layıp PR açabilirsin.
